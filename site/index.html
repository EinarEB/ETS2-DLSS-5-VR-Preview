How these comparisons were made

Two real VR frames, captured with Snowymoon lighting. The exterior uses the latest capture; the cab uses the retained interior capture. Each original was held still and processed through all four quality presets and three neural styles. Clean, Cooler and Cold were then applied using the preview's own color shaders.

Every slider starts from the same ungraded original. Model preset 1, intensity 2 and 100% final blend are fixed. These are processed still frames with zero motion input, not recordings of moving gameplay. They show appearance; flicker and frame rate need a headset test.

The grid uses smaller lossless previews. Full-size images preserve the native 2504 × 2600 pixels without lossy compression. Processing details and image hashes ↗
