# Changes

## v0.1 — release candidate

- Paired-eye image/depth transport for ETS2 OpenXR, with separate neural features and motion history.
- Centered square input, adjustable work resolution and one or two passes per eye.
- Low, Medium, High and Ultra presets; Medium is the default.
- Native game detail composition, optional temporal stabilization and three optional color looks.
- Scroll Lock / Pause comparison with a frame-consistent 0% / 100% blend.
- Local installer with exact-file checks, transactional setup and a separate game home.
- Launcher with quality, style, model preset, intensity, color and comparison controls; restart status and bounded diagnostics.
- Revised direct-driver connection with a process-lifetime session and explicit restart requirement after terminal failures.
- Experimental desktop projection guard with a conservative thread check.

Final headset validation remains pending. The model archive download uses an expiring Discord attachment with a documented fallback; a durable original post link is still desirable. This candidate is not a validated public release.
