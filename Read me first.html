What you need

  • RTX 50-series GPU with 16 GB or more VRAM and the latest NVIDIA driver.
  • Windows 11, 64-bit, and 8 GB free on your ETS2 drive.
  • ETS2's latest VR branch (oculus in Steam → Properties → Betas), DirectX 11 and OpenXR. Setup checks game compatibility.
  • A connected OpenXR headset and your own Snowymoon Lighting access.

2 · Run setup

  1. Open Setup ETS2 VR Preview.exe and select Check files.
  2. Use the suggested new folder on the same drive as ETS2. Leave Create a desktop shortcut selected.
  3. Select Prepare preview, then Open launcher.

The preview has separate settings and saves. Your normal game and campaigns stay in place. Keep the prepared folder where setup creates it.

3 · Connect and drive

  1. Connect your headset and keep Steam open. In Virtual Desktop, select VDXR.
  2. Open ETS2 DLSS 5 VR Preview from your desktop. Start with Medium · Natural · intensity 2 · Cooler and select Start VR.
  3. Create a new local profile with Steam Cloud unchecked and set up your wheel or controller. Activate Snowymoon if prompted; End opens its menu.
  4. Enter the truck and allow initialization to finish. Press Scroll Lock to compare the original image and full neural effect.

Make it yours

Low favors performance. Medium is the recommended start. High uses two passes at reduced resolution; Ultra uses two passes over the full-resolution image.

Close and restart ETS2 after changing quality. Set style, intensity and model in the launcher before starting. Live controls are also available in ReShade.

Home opens ReShade. Use Add-ons → DLSS 5 Feed for VR color, blend and captures. Scroll Lock compares the image while neural processing stays active.

Flicker and distortion can still occur. Try Low or a lower headset resolution if motion is unstable.
